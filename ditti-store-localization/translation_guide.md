# 번역 규칙 — DITTI 스토어 스크린샷

`strings.csv`를 채울 때 따르는 규칙. 이미지 안에 들어가는 글자이므로 **뜻보다 길이와 줄 수가 먼저**다.

## 공통

| 항목 | 규칙 |
|---|---|
| 앱 이름 | `디띠` → 모든 언어에서 **DITTI** (라틴 대문자). 바꾸려면 `glossary.csv`만 고친다 |
| 줄 수 | 한국어와 **같은 줄 수**. 헤드라인이 2줄이면 번역도 2줄 — 셀 안에 실제 줄바꿈을 넣는다 |
| 길이 | 영어는 한국어보다 글자 수가 1.5~2배가 되기 쉽다. 넘치면 의역해서 줄인다. 일본어·중국어는 대체로 비슷하거나 짧다 |
| UI 문구 | 실제 앱의 해당 언어 UI가 있으면 **그 문구 그대로**. 없으면 각 OS의 표준 용어(아래 표)를 쓴다 |
| 반복 문구 | 탭 이름·버튼처럼 여러 화면에 나오는 문구는 한 행으로 두고 `screens`에 `01;03;05` 또는 `*` |
| 날짜·시각 | 언어 형식으로: `10월 14일 (화)` → `Tue, Oct 14` / `10月14日(火)` / `10月14日（二）` / `10月14日 周二` |
| 숫자·통화 | 숫자는 반각. ₩ 금액이 화면에 있으면 `notes`에 표시하고 현지 통화로 바꿀지 결정한다 |
| 사람 이름 | 목업 속 한국 이름(예: 김민지)은 현지 이름으로 바꿀지 `notes`에 표시 — 기본은 현지화 |
| 상태바 | 시각·배터리·통신사는 번역하지 않는다 |

## 언어별

### en — 영어 (미국)
- 헤드라인: 문장형 대문자(첫 글자만 대문자), 마침표 없음. 짧은 동사 시작형 선호 (`Plan your day together`)
- 버튼·탭: Title Case (`Get Started`, `Save`, `Settings`)
- 해요체의 다정한 톤은 `you/your`로 직접 말 거는 문장으로

### ja — 일본어
- 헤드라인: 짧은 구 또는 체언止め. 과한 경어 없이 친근하게
- 앱 안 안내문: です・ます체
- 문장부호: 전각 `、。「」！？`, 숫자·영문은 반각
- iOS 표준 용어: 設定 / キャンセル / 完了 / 保存 / 編集 / 削除 / 通知 / ログイン

### zh-Hant — 중국어 번체 (대만)
- **대만 어휘**를 쓴다. 간체 문장을 글자만 번체로 바꾸면 안 된다
- 문장부호: 전각 `，。！？「」`
- 2인칭은 친근한 소비자 앱이면 `你`
- 표준 용어: 設定 / 取消 / 完成 / 儲存 / 編輯 / 刪除 / 通知 / 登入 / 帳號 / 訊息 / 影片 / 軟體 / 資料 / 網路

### zh-Hans — 중국어 간체 (중국 본토)
- 본토 어휘를 쓴다
- 문장부호: 전각 `，。！？“”`
- 2인칭은 `你`
- 표준 용어: 设置 / 取消 / 完成 / 保存 / 编辑 / 删除 / 通知 / 登录 / 账号 / 消息 / 视频 / 软件 / 数据 / 网络

### 대만 vs 본토 — 자주 틀리는 짝

| 한국어 | zh-Hant (대만) | zh-Hans (본토) |
|---|---|---|
| 저장 | 儲存 | 保存 |
| 로그인 | 登入 | 登录 |
| 계정 | 帳號 | 账号 |
| 메시지 | 訊息 | 消息 |
| 동영상 | 影片 | 视频 |
| 데이터 | 資料 | 数据 |
| 네트워크 | 網路 | 网络 |
| 정보 | 資訊 | 信息 |
| 품질 | 品質 | 质量 |
| 사용자 | 使用者 | 用户 |
